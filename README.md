# Version Control SBA

This repository contains the website and written materials for the Version Control skills-based assessment.

GitHub repository: https://github.com/Vierbytes/version-control-sba (private)

## Files

- `index.html` contains the header, navigation, hero, about, testimonials, contact form, and footer.
- `REFLECTION.md` describes the branch and review workflow.
- `REVIEW_QUESTIONS.md` is a short study guide for the module topics.
- `SELF_REVIEW.md` records a review of the finished project.

Each assignment lives in this repository only. The repository is private while the work is being prepared.

## Pull request review

The requested self-review checklist is included in `SELF_REVIEW.md`. GitHub does not allow the author of a pull request to approve their own pull request, so this checklist is not presented as a formal approval or peer review.
